## 🔬 Research Interests

- **Multi-robot task allocation** — decentralized coalition formation and cooperative transport
- **Behavior Trees for mission autonomy** — multi-agent BT frameworks on ROS 2
- **Manned-unmanned teaming (MUM-T)** — AI decision support for multi-aircraft missions
- **AI agents for air-combat simulation** — reinforcement learning and LLM-driven play
- **UAV perception** — low-cost target localization from onboard cameras
